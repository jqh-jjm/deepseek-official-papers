## 阅读与使用

- **在线跳页**：在 GitHub 打开 PDF 后，在地址栏 URL 末尾加上 `#page=N`（如 `#page=212`）即可跳到对应论文首页。
- **本地阅读**：两份 PDF 均内嵌书签目录（封面 / 目录 / 01 … 24），在 PDF 阅读器侧边栏即可按篇跳转。
- **克隆仓库**（约 74 MB，建议浅克隆）：

  ```bash
  git clone --depth 1 https://github.com/jqh-jjm/deepseek-official-papers.git
  ```

- **完整性校验**：见 [`CHECKSUMS.txt`](CHECKSUMS.txt)（SHA-256）。
